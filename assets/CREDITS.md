# Asset-Quellen

Alle Grafiken sind **Platzhalter** und werden durch eigene Pixel-Art ersetzt (siehe `docs/design.md`).
Vor einer Veröffentlichung müssen alle Platzhalter ohne passende Lizenz entfernt sein.

| Datei | Quelle | Lizenz |
|---|---|---|
| `sprites/player/player.png` | Mystic Woods (Free) von Game Endeavor | nur nicht-kommerziell, keine Weitergabe → `licenses/mystic_woods_read_me.txt` |
| `sprites/items/apple.png` | Mystic Woods (Free) | wie oben |
| `sprites/objects/mystic_woods_objects.png` | Mystic Woods (Free) | wie oben |
| `ui/inventory_background.png`, `ui/inventory_slot.png` | Mystic Woods (Free) | wie oben |
| `sprites/objects/door_open.png`, `door_closed.png` | Dungeon Crawl Stone Soup Tiles (Okt. 2010) | CC0 → `licenses/crawl_tiles_license.txt` |
| `tilesets/dungeon_tileset.png` | unbekannt | **unbekannt, prüfen** |
| `sprites/enemies/slime.png` | Mystic Woods (Free) | nur nicht-kommerziell, keine Weitergabe → `licenses/mystic_woods_read_me.txt` |
| `sprites/pickups/*.png` (Rubine, Herz, Schlüssel), `sprites/objects/pot.png`, `grass.png`, `locked_door.png`, `save_statue.png` | eigene Platzhalter, erzeugt mit `tools/make_placeholders.py` | frei |

**Wichtig:** Mystic Woods (Free) darf nicht weitergegeben werden. Das Repo muss deshalb privat bleiben, solange diese Dateien enthalten sind.
